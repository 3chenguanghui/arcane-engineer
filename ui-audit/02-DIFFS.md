# 02 · 差异清单（同一元素 ≥2 个值）

> 规则：每条给出「值 A（位置）｜值 B（位置）」→ **判定：留哪个 / 改哪个 / 为什么**。判定依据只两条：①令牌里已有该角色 ②可读性数值（见 01 附注 B）。
