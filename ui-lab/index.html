01

技能卡

奖励弹窗里四选一的那张卡。要同时解决三件事：稀有度一眼可读、伤害 / 冷却 / 耗蓝能扫、 在 228px 的真实卡宽下不挤成一团。三套方案卡高分别是 224 / 178 / 196px。

新窗口打开 ↗
A 刻度 推荐

保留原卡结构，只在品质区加 4 枚菱形刻度、底部加一条三格数值轨。改动最小，四选一仍一屏放得下。

卡高 224px · 数值 15px/700 · 标签 9.5px
B 铭牌 贴底条

横向紧凑、图标上移、数值做成三枚胶囊。适合贴在屏幕底部的奖励条，不占中央视野。

卡高 178px · 图标 38px · 胶囊 24px 高
C 主数 卡组页

把伤害做成主角（25px），冷却与耗蓝降为小芯片，左侧用四格竖条表示品质。适合卡组查看页。

卡高 196px · 伤害 25px · 品质条 4 格
预览窗 · 已定位到方案区
推荐 A 理由：稀有度有颜色 + 刻度数量 + 描边粗细三路编码，灰度也能读；三个数字固定同一列位，不和 12.5px 描述混排。 实测截图
02

结算面板

一局结束后的 720px 面板。只回答三件事：这局发生了什么、比上局好还是差、下一步按哪个按钮。 三套方案共用同一组数据（第 12 层 / 08:41 / 87 击杀 / 上局第 9 层），所以对比的是信息顺序，不是"好不好看"。

新窗口打开 ↗
A 结论条 推荐

单列到底：结论 → 三格大数（差值贴在同格下方）→ 明细 → 主 / 次按钮。手机与桌面同一套顺序。

层级 4 层 · 大数 30px · 按钮 46 / 38
B 战报 叙事

左侧一段"这一局怎么死的"叙述 + 右侧四行指标右对齐。适合想要临场感、且屏幕较宽的情况。

双栏 1fr / 296px · 指标行 34px · 差值列 74px
C 对照表 复盘

本局 / 上局 / 差值三列并排，最适合"我到底进步了吗"的复盘场景，数字密度最高。

列宽 1fr 96 96 92 · 本局 16px · 上局 12.5px
预览窗 · 已定位到方案区
推荐 A 理由：结论和数字分两档、差值不单开一行、主按钮是 46px 填色而次按钮只有 38px 描边，视线不会在两个按钮之间犹豫。 看 1:1 实宽
