## 4. 贴法

### 4.1 推荐：脚本（会自己校验）

```powershell
cd 'D:\其他\TRAE宝\奥术工程师\ui-lab\title-bg-patch'
node apply-titlebg.mjs              # dry-run：只报锚点命中 / 贴前 / 贴后 / 增量
node apply-titlebg.mjs --write      # 真正写入；贴前 MD5 不等于构建基线会拒绝执行
```

- 基线漂移（正常情况）时脚本会提示并退出（退出码 3）；确认合并顺序无误后加 `--force` 继续：
  `node apply-titlebg.mjs --write --force`
- 贴后脚本自动回读校验，不一致直接报错（退出码 4）。

## 5. 贴后验收（三条必须全过）

| 项 | 判定标准 |
|---|---|
| 布局未被带跑 | 1280×800 截图里标题、开始按钮、难度卡、天赋面板位置与合并前一致；难度/天赋面板内无弧线穿过 |
| `?bg=off` | `getComputedStyle(#titleBg).display === 'none'`；`frames === 0`；`running === false` |
| 进游戏停表 | 「开始探索 → 选角色 → 以此角色开始」后 `running === false`，`frames` 冻结不再增长 |

参考数值（本机实测，1.5 dpr 上限、1280×800）：

- 背景自身稳态 **≈0.91 ms / 帧**（含前景徽记 1.01 ms，p95 1.7 ms）；
- 冷初始化（图集 + 底图 + 粒子）**≈6.3 ms**（热载）；
- 实盘全帧平均明度 **15.7/255**。
