| **任意时刻** | 全局 | **点击 / 按键任意处 → 立即跳过进场，直接到终态** | ≤16（一帧） | 无 |

**跳过进场的实现**（写权线照这个做）：

- 在 `capture` 阶段监听 `pointerdown` 与 `keydown`（含 Esc / 空格）；触发一次即移除监听。
- 对进场时间线里所有 Web Animations 调 `finish()`，直接停在终态；背景旋转与按钮呼吸保留（它们不是进场）。
- 跳过当帧就把按钮 `pointer-events` 置为 auto，不等待原时间线。
- 防误触：跳过后的 **200ms 内**按钮的 `click` 不触发开始（`suppressClickUntil = now + 200`），避免“点一下跳过，顺手把游戏开了”。
- 硬上限：**可点时间 ≤1200ms**（本时间线为 1150ms）。

要点：0–1s 只让字标聚形；按钮在 1.15s 内一定可点，且任何时候点一下都能立刻到终态——进场可以慢，但不能锁住操作。

## 验收硬指标

### 1) 字标与背景最亮处的对比度（具体值）

- 现状：金 #ffc247（L=0.612）对背景最亮 RGB(201,171,99)（L=0.424）→ **1.4:1**；`22D28003` 快照背景变暗到 RGB(171,146,87)（L=0.299）→ **1.9:1**；390 档 **1.3:1**。区间 **1.3–1.9:1**。
- 大字要求 ≥ **3:1**，但**不要过头**：用 **#7a6645**（L=0.140 → **3.48:1**）这一档就够；不要再往下压到 #6e5a3d，更不要为了凑数字把符阵压成一片灰。
- **判据改成两条，必须同时成立**：
  1. 字标 #ffc247 与背景最亮处 ≥ **3.0:1**（即背景最亮 L ≤ 0.171）；
  2. 背景符阵最亮格与最暗格仍有可辨差异：把 canvas 按 **12×7** 分格（1920 档每格 160×154），每格取平均亮度；**最亮格 L 落在 0.05–0.171**（既不抢字，也不能暗到看不见），且最亮格 / 最暗格 ≥ **1.30:1**，暗格 L 保持 ≤ 0.02（不许用整体叠灰的方式抬暗部）。
- 做法：**按亮度比例乘系数压暗**（当前两次快照：L 0.299 → ×0.47；L 0.424 → ×0.33），不是叠加半透明灰；粒子峰值透明度同比降即可，不改背景色相。
- 正文：副标 #a8bfdc 对底 #070b14 = **10.5:1**（≥4.5 ✅）；统计标签 #7f90a8 对同底 = **6.1:1**（≥4.5 ✅）；版本角 #6b7c91 @62% ≈ 2.44:1（装饰性，不达标，保留但不可承载信息）。

### 2) 48px 缩略图可辨

- A / B：可辨（横竖比与断口在 45.5px 墨高下仍成立）。
- C：勉强可辨（收细端 0.5–1px），只建议用于大字场景，不做通用缩略。

### 3) 两档不散架

- 1920×1080：字标墨高 205px（19.0%），三列布局宽 1920，无溢出。
- 390×844：字标墨高 120px（14.2%），单列，无横向滚动；页面纵向滚动 1 屏以内。
- 截图：`ui-lab/glyph-lab-1920.jpg`、`ui-lab/glyph-lab-390.jpg`（JPEG q85）。

### 4) 可点与跳过（新增，硬性）

- 可点时间 **≤1200ms**：本时间线 1150ms。
- **点击 / 按键任意处**立即跳过进场、直接到终态，响应 **≤16ms（一帧）**；跳过当帧按钮即可点。
- 跳过后的 **200ms** 内不触发“开始”，防止误触。
- 只锁视觉、不锁操作：进场再慢也不能让按钮晚于 1200ms 可用。

## 附：踩坑记录（v1.8.2 字标 A 落地时实测发现）

### 坑 1：SVG 字标被启动代码洗回纯文字

`index_arcane_v2.html` 里有一段标题渲染逻辑（约 16664–16676 行）：

```js
const wordmarkEl = document.getElementById('titleWordmark');
if (wordmarkEl) {
  wordmarkEl.innerHTML = wordmark(title);   // ← 把整个 h1 的内容重写
  wordmarkEl.setAttribute('data-title-len', String(Array.from(title).length));
}
```

它会在启动时无条件覆写 `h1` 的 `innerHTML`，于是 HTML 里写好的 `<svg class="wordmark-glyph">` 在运行时被换成 `<b>烬</b>` 文字。
表现：CSS 里 SVG 规则都在，`getComputedStyle(h1).fontSize` 也确实是 104px，但 `document.querySelector('#titleWordmark svg')` 返回 `null`，页面上看到的仍是系统字体的文字。

**这是"改了却没生效"的同一族问题：静态读源码看不出，必须回读运行时 DOM。**

已修（保留单字 SVG）：

```js
if (!(Array.from(title).length === 1 && wordmarkEl.querySelector('svg'))) {
  wordmarkEl.innerHTML = wordmark(title);
} else {
  wordmarkEl.setAttribute('aria-label', title);
}
```

**以后凡是往 `#titleWordmark` 里塞自定义节点，都要先查有没有这段 innerHTML 覆写。** 同理适用于 `#titleKicker`、`#titleTagline`、`#aboutBody`。

### 坑 2：验证必须回读渲染值，不能只看 CSS 文本

同一选择器写两遍、后者用 `var(--fs-display)` 压回 64px 的问题，只看源码里的 `clamp(56px,13vh,104px)` 会误判成"已经放大了"。判据只有一条：

```js
getComputedStyle(document.getElementById('titleWordmark')).fontSize
```

实测（v1.8.2，字标 A）：
- 1920×1080 → `104px`，SVG 盒 235.9×216，墨高 204.8px = 18.97%H

### 坑 3：`apply-titlebg.mjs` 的构建基线会因前置改动失效

字标 A 落地后主文件 MD5 变成 `13D9C718FCC7FBC7B9EF5A23F329E0DF`，而背景补丁记录的是更早的基线，`--write` 因此以 **退出码 3** 拒绝写入（锚点 5/5 全中、内容能算出 +18,427 B，但基线校验不过）。

这是设计内的保护：基线漂移说明主文件在本补丁撰写之后被其他批次写过，必须先确认顺序，不能 `--force` 硬贴。
