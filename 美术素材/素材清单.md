## 4. 体积账（内嵌进单文件的预算）

| 项 | 字节 | 说明 |
|---|---:|---|
| 贴图 5 张 | 176,406 | 磁盘实测 |
| 图标 16 张 | 7,683 | 磁盘实测 |
| **原始合计** | **184,089** | `SUM` 实测 |
| **base64 合计** | **245,484** | 逐文件 `ceil(n/3)*4` 求和 |
| 占 1.5 MB 预算 | **15.6%** | 分母 1,572,864 B |
| 内嵌后 tokens.css | 240,230 | 含 5 张 `data:` URI + 98 条声明 |

压缩方式：**WebP（q80）+ 灰度化 + 降采样 384/256**；图标保持 **SVG 矢量**、不合并图集（图集需 1 张 ≈40KB 位图，反而更贵）。
被否决的方案（有实测）：512px WebP 82–113KB/张（过大）；512px 256 色 PNG **235–243KB/张**（灰度噪声调色板退化，比 WebP 大 2.3–2.9 倍）；Kenney 官方 zip 直链返回 HTML 非压缩包，未能取得。

## 5. 使用规则

| 贴图 | 用在哪 | 透明度 / 混合 / 尺寸 |
|---|---|---|
| metal | `.hud-deck`、`.btn`、`.floor-panel` 边框 | `.10` / `overlay` / `192px` |
| concrete | 面板底、`.modal` 背板 | `.08` / `overlay` / `384px` |
| ground | 场景地板（Canvas 或 `.stage`） | `.16` / `multiply` / `384px` |
| surfaceimperfections | 全屏刮痕（`body::before`） | `.04` / `soft-light` / `512px` |
| grain | 所有面板 `::after` 噪点 | `.05` / `overlay` / `96px` |

禁用：不得把贴图当"主视觉大图"铺满；不得在贴图上再加 `filter: saturate()` 改色（会破坏灰度中性，且与"8bit 灰度分档"冲突）。

循环做法（可复现）：取源曲 0–27s；把 25–27s 与 0–2s 做 2s 三角窗交叉淡化放在循环头部，

加载规则：`src` 只在**首帧之后的 idle** 里读取并 `preload='auto'` 预解码，boot 阶段不读 base64；
默认关闭（`AUDIO_CONFIG.bgmDefaultOn=false`），用户在设置里打开才播放。
