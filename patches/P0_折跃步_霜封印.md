> **基线含熔炉房 ON（G1）｜真·全关 = G0。**
> 2026-11-09 叠加矩阵暴露了一个前提错误：口径头里那个 34.1 / 36.4 / 35.9 / 36.4
> 一直**带着熔炉房**，README 式的叫法却是"基线"。把 `C.ROOM.plan` 置空重跑，

> 两个数只差 0.2–0.3pp（10 层）/ 0.6–0.8pp（F20），但**名字必须和内容一致**。

规则（缺一条就视为报告无效）：

1. **三样缺一不报**：MD5、基线四口径、样本数。
2. **MD5 变了 = 模型被改过**，上一份结论作废，必须在新模型上重跑，不许拿旧数换算。
3. **两组数打架先查 MD5**，不要先怀疑参数。
4. `tools/p0_probe.js` 已自动打印这三行 `【口径头】`，直接复制进报告，别手抄。
5. **±0.1pp 自然抖动豁免（长期规矩）**：基线允许 **±0.1pp** 的抖动，但每份报告必须带
   `config.js` 与 `sim.js` **双 MD5**。只要两个 MD5 都没变，**±0.1pp 不许拿来说"结论变了"**；
   反过来，任一 MD5 变了就必须整份重跑，不许拿旧数换算。判定留/删卡看的是与门禁的**余量**，
   不是 0.1pp 这种末位差。
6. **"基线"必须带开关标签（长期规矩）**：任何报告里的"基线"字样，必须一眼看出开了哪些开关；
   写不下就用编号（G0 全关 / G1 熔炉 / G4 线上 / G5 +敌潮），**不许裸叫"基线"**。
   口径头固定带一行：`基线含熔炉房 ON（G1）｜真·全关 = G0`。

## 3. 判定（门禁：四口径全部 ≤38.5% / F20 ≤35%）

| 版本 | 最差 10 层 | 最差 F20 | 结论 |
|---|---|---|---|
| 原版（无敌 0.25s / 定身 0.9s / 4s·3s） | 42.4% | 37.4% | **FAIL** |
| **落地版（无敌 0.10s / 定身 0.6s / 5s·4s）** | **38.2%** | **33.4%** | **PASS** |
| 指定版（无敌 0.10s / 定身 0.6s / 4s·3s） | 39.0% | 34.0% | **FAIL**（超 0.5pp） |

结论：**只放落地版。** 指定版冷却更短、无敌/定身时长没跟着降，上限口径破线 0.5pp。
要强行用 4s·3s，必须再砍无敌（0.10 → 约 0.05）或定身（0.6 → 约 0.4）；
那已经是第三轮调参，按约定**停止并报结构性结论：当前基线（观星 36.4%）只剩 2.1pp 余量，
容不下两张都带生存收益的卡同时按更短冷却上线。**

  // ---- ⑦ 折跃步：沿瞄准方向找最远可站立点瞬移｜落地小爆 ----
  if (cfg.kind === 'blinkStep') {
    const dirX = Math.cos(angle);
    const dirY = Math.sin(angle);
    let landX = player.x;
    let landY = player.y;
    /* 从最远距离往回收，取第一个能站人的点：撞墙时自动缩短落点，不会瞬移进墙 */
    const radius = player.radius || GAME_CONFIG.playerRadius || 14;
    for (let step = cfg.distance; step >= 40; step -= 20) {
      const nx = player.x + dirX * step;
      const ny = player.y + dirY * step;
      if (isWalkableCircle(nx, ny, radius)) { landX = nx; landY = ny; break; }
    }
    addBeam([{ x: player.x, y: player.y }, { x: landX, y: landY }], hexToRgba(color, 0.72), 0.18, 12, false);
    addRing(landX, landY, 10, hexToRgba(vfx.accent, 0.85), cfg.blastRadius, 0.26, 'shockwave');
    addSparks(landX, landY, vfx.accent, 8);
    playSfx('frost', 0.6);
    player.x = landX;
    player.y = landY;
    player.invuln = Math.max(player.invuln || 0, cfg.invuln);
    for (let i = state.enemies.length - 1; i >= 0; i -= 1) {
      const enemy = state.enemies[i];
      if (!enemy || enemy.hp <= 0) continue;
      if (dist(landX, landY, enemy.x, enemy.y) > cfg.blastRadius + enemy.radius) continue;
      damageEnemy(enemy, damage, Math.atan2(enemy.y - landY, enemy.x - landX), { abilityId: magic.id });
    }
    return;
  }

  // ---- ⑧ 霜封印：落点 r80 冻结 0.6s｜复用既有 frozenTime，零引擎改动 ----
  if (cfg.kind === 'rootSingle') {
    const point = aoeAimPoint(320);
    addRing(point.x, point.y, cfg.radius, hexToRgba(vfx.accent, 0.85), cfg.radius + 18, 0.30, 'hex');
    addRing(point.x, point.y, 8, hexToRgba(color, 0.60), cfg.radius, 0.34, 'rune', 1.2);
    addSparks(point.x, point.y, vfx.accent, 8);
    playSfx('frost', 0.8);
    const record = aoeRecord(magic.id, cfg.shape, { radius: cfg.radius, root: cfg.root },
      { x: point.x, y: point.y }, { x: point.x, y: point.y });
    for (let i = state.enemies.length - 1; i >= 0; i -= 1) {

      if (dist(point.x, point.y, enemy.x, enemy.y) > cfg.radius + enemy.radius) continue;

      enemy.frozenTime = Math.max(enemy.frozenTime || 0, cfg.root);
      damageEnemy(enemy, damage, null, { abilityId: magic.id });
      aoeRecordHit(record, enemy);
      if (enemy.hp > 0) addSparks(enemy.x, enemy.y, vfx.accent, 4);
    }
    return;
  }
