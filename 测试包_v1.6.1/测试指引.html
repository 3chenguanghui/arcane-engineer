开始之前（30 秒）：

2）先双击 自检.html 跑一遍自动检查（约 3 秒），它会把「能不能开局、能不能下楼、存档能不能写、设置能不能生效、有没有报错」逐项打勾 / 打叉。
3）自检全绿后，再双击 烬_v1.6.1.html 做人工试玩。自检结束会自动把存档还原，不会弄脏你的进度。

第一档 · 3 分钟快速验 只要有一项不对，就先别继续往下测

01

双击 自检.html（就在本指引旁边）。

屏幕中间弹出一块深色面板，自动出现 10 行检查，每行前面是绿色 ✓，每行右侧写着实测数字；约 2.4 秒后底部出现绿色总结「全部通过：10/10 项」。

面板没出现 / 一直停在「正在检查」：说明文件被改坏或浏览器太旧，先换 Edge 再试。某一行是红色 ✗：把那一行的整句文字抄下来发给开发者，不要继续后面的步骤。

02

双击 烬_v1.6.1.html（正式游戏）。

出现标题页：正中间大字「烬」，下面一行小字副标题；再下面并排三个数字「最佳楼层 / 奥术结晶 / 已完成局数」；主按钮「开始探索」；底部有三档难度「简单 / 普通 / 困难」，默认高亮普通；角落有小字版本号 v1.6.1。

黑屏、白屏、只看到文字没有背景、按钮点不动：记下现象直接反馈。标题只有「烬」但没有任何按钮，也算失败。

03

点「开始探索」（或直接按 Enter）。

标题页淡出，进入第 1 层：画面中央是你的角色，左上角出现生命条（新手满血一般是 100 / 100），左下是奥能条，右侧有小地图；第一次玩会弹一条短教学提示。

标题页没消失 / 进去后全黑 / 角色和血条都没有：失败。若提示被弹窗挡住看不到，也算一个问题，记下来。

04

按 W A S D（或方向键）走两步，再松手；试着撞一下墙。

角色按方向平滑移动，镜头跟着走；松手马上停；撞墙会被挡住，不会穿过去。

角色不动 / 一直滑不停 / 穿墙 / 镜头不跟：任意一条都算失败。

05

把鼠标移到敌人身上，点鼠标左键（也可以按 J）。

角色朝准星方向打出一发火球（有清晰弹道），左下奥能条肉眼可见地减少；打中的敌人掉血、身上闪白、被轻微击退。

点了没反应 / 有弹道但敌人不掉血 / 奥能条不减：失败。注意：奥能空了打不出弹道是正常设定，等一两秒回蓝再试。

06

把本层敌人全部清光（普通难度第 1 层大约 8–11 只，地图上红点都要消失）。

先弹「楼层清空 · 技能四选一」：四张卡，按 1~4 或点击选一张；接着弹「楼层被动 · 三选一」，按 1~3，或点「跳过被动」。选完后地图上的楼梯亮起。

清光了不弹选卡（卡在原地） / 选完卡后楼梯不亮 / 按键数字没反应：失败。

07

走到亮起的楼梯上，按 E。

出现一次短促的转场，层数变成 第 2 层（顶部 / 右上角楼层数字变化），角色生命回满一小截、奥能回满，重新出现新地图和敌人。

按 E 没反应：先确认角色确实站在楼梯范围内（贴得太远会提示距离），再把角色踩到楼梯正中心按一次；还不行算失败。层数不变 / 黑屏卡住也算失败。

08

按 O 打开「设置」，找到「画面 · DISPLAY」里的「性能模式」，点一下开关，再点一下关掉，最后按 Esc 关闭面板。

开关从「关 · 全画质」变成「开 · 粒子 xx% / 迷雾 xx%」，画面粒子 / 雾气明显变少；再点回「关 · 全画质」又恢复；Esc 能正常关掉面板并继续玩。

开关点了没字变化 / 画面完全没变化 / 关不掉面板：失败。

09

直接关掉这个标签页，再双击一次 烬_v1.6.1.html。

标题页的「最佳楼层」至少是 2，「已完成局数」比刚才多；主按钮下方多出一个「继续上次」按钮，点它可以直接回到刚才那一层继续打。

数字归零 / 没有「继续上次」/ 点了继续提示已损坏：说明存档没写进去，失败。

第二档 · 15 分钟完整验 按 A→E 顺序做；标「可选」的不影响交付判定

A 组 · 战斗与按键（约 4 分钟）

A1

在局内依次按 1 2 3（能切几张取决于已解锁数量），再按 4~6。

底部卡组里对应卡牌高亮外框，准星 / 弹道颜色随之变化；按未解锁的数字键无反应是正常的。

按了完全没变化 / 高亮的不是同一个槽 / 弹道颜色没换：失败。

A2

贴近敌人，按 Q 挥近战；再按一次 Q 连挥。

角色身前出现扇形弧光，命中敌人掉血并击退；奥能条不下降（近战不耗蓝）。

没有弧光 / 奥能被扣 / 近距离也打不到：失败（除非设置里把「近战武器（Q）」关掉了，这种属正常，去设置里打开再测）。

A3

按 Shift 影步冲刺；再用鼠标右键按一次装置。

Shift 有一次明显的前冲 / 位移；右键触发科技装置（如护盾 / 炮台，取决于已解锁内容），画面上出现对应特效。未解锁时无反应是正常的。

冲刺没有位移 / 右键没有任何特效且已解锁对应装置：失败。

A4

打掉一波敌人时留意屏幕右上 / 顶部的击杀数、连杀提示；按 G 打开图鉴，再按 G 关闭。

击杀后提示正常跳出；图鉴面板能打开，里面有怪物 / 魔法 / 装置条目，点击条目能看到说明；再按 G 或 Esc 能关闭并继续玩。

图鉴空白 / 打不开 / 关不掉后角色不能动：失败。

B 组 · 关卡流程与交互（约 4 分钟）

B1

进入新的一层，先看右侧小地图：找到带「宝箱」图标的房间，走进去，靠近宝箱按 E。

宝箱打开动画 + 一次奖励（卡牌 / 结晶 / 治疗），顶部弹出获得提示。

按 E 没反应 / 宝箱开了但没提示：失败。

B2

找到带紫色裂纹的「裂隙」房间，靠近按 E；如果弹出确认，再按一次 E。

第一次按出现「是否穿越」类提示，第二次按执行穿越 / 或提示条件不满足；无论成功失败都有文字反馈，不会静默。

连按两次完全没有任何提示 / 按下后角色卡死：失败。

B3

找到「商店」房间（门牌上有商店标记），靠近按 E。

弹出商店面板，列出 3 件左右商品与价格（结晶）；买得起就买一件，结晶扣减、物品进背包 / 卡组。

商店打不开 / 买了不扣钱 / 扣了钱没给东西：失败。

B4

清空整层后按 M 看全屏地图，再按 M 关闭；然后去楼梯按 E 进入下一层。

全屏地图显示已探索房间、楼梯位置与你自己的位置标记；关闭后照常能走能打。

地图空白 / 关掉后角色不能动 / 楼梯位置标错：失败。

B5

可选（需先装开发者开关补丁）：打开 烬_v1.6.1.html?dev=1，局内按两次 ] 跳到第 6 层，清完小怪见首领。

第 6 层出现区域首领「机械暴君」（称号「熔铸核心 · 第一层守门者」）：血条明显比普通怪长、有专属技能、击杀后掉落高品质奖励并进入第 7 层。

第 6 层没有首领 / 首领血条和普通怪一样 / 击杀后卡住：失败。未装补丁时这一项记「未验」，不影响其它结论。

C 组 · 存档与长线（约 3 分钟）

C1

回到标题页，点「存档槽」。

展开 3 个槽位；每个槽显示层数 / 时间；有档的槽按钮是「继续 / 导出 / 删除」，空槽是「空槽 / 导出 / 删除」。点「继续」能回到该槽记录的层数。

没有 3 个槽 / 点继续没反应 / 导出的文本为空：失败。

C2

点「今日挑战 · 2026xxxx」按钮开局，玩到第 1 层以上后退出，回标题页看「种子成绩」区域。

开局后种子被固定（同一天所有人同一套布局）；标题页出现一条「今日 2026xxxx · 最高 N 层」的成绩条。

按钮文字没有日期 / 成绩不出现：失败。

C3

在标题页「种子」输入框里输入 8 位数字（例如 12345678），点「用种子开始」。

正常开局；退出后标题页种子成绩里出现 12345678 这一条。

提示种子不合法（1–24 个字符都合法，空才不合法）/ 成绩不记录：失败。

C4

标题页右侧「永久天赋」：结晶够就先点任一升级按钮（不够就先去打一局拿结晶），升完关掉游戏重新打开。

点升级后结晶减少、等级 +1、旁边数值说明变化；重开后等级仍在、结晶余额正确。

点了不扣结晶 / 等级不涨 / 重启后归零：失败。

C5

可选且不可恢复：设置页（O）最下面点「清空存档」。只在你确认这台电脑上的进度可以丢时做。

弹出确认提示；确认后标题页「最佳楼层 / 结晶 / 局数」清零，天赋等级归零。

没有二次确认 / 清了数字还在：失败。

D 组 · 设置与画面（约 2 分钟）

D1

按 O 打开设置，依次切换：色盲模式、后处理特效、泛光 / 色差 / 扫描线 / 暗角、辅助瞄准三档。

每个开关点一下都有文字状态变化，画面有对应变化（色盲模式会改描边 / 配色；关后处理画面变"平"；辅助瞄准切「关闭」后弹道完全跟手不吸附）。关面板后设置被记住。

某个开关点了没状态文字 / 画面完全不变 / 关掉面板再开又变回默认：失败。

D2

在设置里拖动「BGM 音量」「音效音量」滑块；按 N 静音再按一次恢复；回标题页点「声音 · 开」。

滑块数字实时变化；按 N 画面顶部出现静音提示、声音消失，再按恢复；标题页按钮文字在「声音 · 开 / 关」之间切换。

滑块拖了数字不变 / N 无提示：失败。注：BGM 默认是关闭的，只有环境层，听不到 BGM 不算 bug。

D3

把游戏窗口从最大化拖成小窗口，再拖回来。

画面等比适配窗口，不出现黑边、拉伸、UI 叠在一起；小地图 / 血条位置仍在屏幕内。

画面被裁掉 / UI 跑到屏幕外 / 模糊拉伸：失败。

E 组 · 稳定性（约 2 分钟）

E1

局内按 F5 刷新页面。

回到标题页；「继续上次」可点，并能回到刷新前最近一次自动保存的层数；标题页数字没有归零。

白屏 / 提示存档损坏 / 数字归零：失败。

E2

连续玩 2 层以上，期间反复开 / 关设置、图鉴、地图；观察帧率（目测是否卡顿）并看有没有红字弹窗。

全程流畅、没有红字报错弹窗、没有卡死；关面板后操作正常。

明显掉帧 / 弹红字错误 / 卡死需要刷新：失败（把弹窗文字记下来）。

E3

可选（会看一点电脑）：按 F12 打开开发者工具，点上方「Console / 控制台」，再玩 1 分钟。

控制台没有红色错误行（黄色提示、灰色日志可以忽略）。

出现红色报错：把红字整段抄下来反馈。

失败怎么记 按这个格式发给开发者，能最快定位

步骤编号（例如 B1）+ 你点了什么 + 应该看到什么 + 实际看到什么 + 截图（有的话）。
例：B1｜第 3 层宝箱房按 E｜应弹出奖励｜实际完全无反应，截图见附件

附：这些现象不是 bug 省得白记一条

  • BGM 默认关闭，只有很轻的环境层；听不到"音乐"属正常，可在设置里打开。
  • F（融合）、K（装置）、Tab（换相）在未解锁时按了完全没反应，是刻意设计。
  • 第 1 层开局会有一条教学提示，跳过后不会再来。
  • 每层清空会连续弹两次选择（技能四选一 → 被动三选一），第二次可以点「跳过被动」。
  • 首领只在第 6 / 12 / 18 层出现，前 5 层没有首领是正常的。
  • 「清空存档」会永久清掉本机进度，不可恢复。
  • 自检页 自检.html 跑完会把存档自动还原，所以自检后标题页数字没变是正常的。

附：两个配套文件

自检.html：自动检查页（10 项，约 3 秒）。改完代码想确认"还能开机"，先双击它。

开发者开关_补丁.md：给开发者用的 ?dev=1 补丁说明。打上后可以用键盘快速跳层、回血、加结晶、切换天赋，方便复现问题；默认不生效，不影响正式玩法。
