# L1 · 冲刺穿身挂「裂印」（spec · 决策完成版）

> 来源：`.spec/round4-5-merge.md` 结构性根因 **L1「进攻动词单一」**。
> 一句话根因：**玩家的进攻只有"按左键放法术"一个动词；冲刺是纯位移+无敌，不参与任何伤害决策，所以位移永远只是"躲"。**

## 目标
把冲刺从"逃生键"改成**第二个进攻动词**：穿身 → 打标记 → 法术命中吃加成并引爆。玩家会自然产生"先冲进去、再打一发"的组合动作。

## 数值（先定默认，后续只调这里）
| 项 | 值 | 说明 |
|---|---|---|
| 裂印持续时间 | **3.0s** | 与"3s 内被法术命中"对齐 |
| 命中加成 | **×1.4** | 明确可验证（≥1.2 的强感知线） |
| 引爆伤害 | **18**（×全局增伤） | 小范围，不抢主技能伤害 |
| 引爆半径 | **70px** | 约两个身位，够"顺带清一圈杂兵" |
| 挂印判定余量 | **+6px** | 冲刺速度快（620/s），留一点容差 |
| 触发次数 | 每个敌人**一次** | 命中即消耗，避免反复叠加 |

## 决策
| # | 问题 | 决策 |
|---|---|---|
| D1 | "被法术命中"判定 | 走 `damageEnemy()` 单一入口，**任何**直接伤害命中都消耗裂印。理由是该项目所有伤害都从这一个入口进（法术/科技/引爆），在入口做特判会复制结算逻辑。 |
| D2 | 引爆是否伤主目标 | **不伤**。主目标已吃 ×1.4 主伤害，引爆只波及周围敌人，避免"单目标翻倍"破坏平衡。 |
| D3 | 连锁引爆 | **允许一层**：被引爆波及的敌人若也带裂印，会各自引爆；用 `state.detonating` 守卫避免递归爆炸。 |
| D4 | 首领是否可挂印 | **可挂**，但引爆伤害对首领只有 50%（沿用 `enemy.isBoss` 抗性思路）。 |
| D5 | A/B 口径 | `state.dashMarkV1`（默认 true）；false = 旧版（无挂印、无加成、无引爆、无视觉）。 |

## 改动落点
| 位置 | 改动 |
|---|---|
| `DASH_CONFIG` 之后（L4499） | 新增 `DASH_MARK_CONFIG` |
| `state` 初始化 | `dashMarkV1: true`、`detonating: false` |
| `updatePlayer()`（冲刺位移之后） | `tickDashMarks(dt)` 递减计时 + `applyDashMarks()` 穿身检测 |
| `damageEnemy()`（无敌判定之后、暴击之前） | 读裂印 → `damage *= 1.4` 并消耗；伤害结算后 `detonateDashMark(enemy)` |
| 敌人绘制循环（地面投影之后，L15404） | `drawDashMark(enemy, t)` 紫色双环 + 剩余时间刻度 |
| `__roamDebug` | `dashMark()` 快照 / `setDashMarkV1(on)` / `markEnemy(id)` 便于断言 |

## 验收断言
| 项 | 口径 |
|---|---|
| 挂印 | 冲刺穿过后 `enemy.mark.timer > 0`，初始 ≈3.0 |
| 剩余时间 | 0.5s 后 timer 明显下降（说明按世界时间走） |
| 加成 | 同一敌人：无印 vs 有印，`damageEnemy` 前后血量差比 ≥1.4 |
| 消耗 | 命中后 `mark.timer === 0`（不会连续吃两次） |
| 引爆 | 引爆后旁边敌人掉血，且主目标不再额外掉血 |
| A/B | `setDashMarkV1(false)` → 冲刺穿过后没有 mark，命中倍率 1 |
| 回归 | 14 套全绿；fps 用"复跑取稳定值/跳过首帧"口径 |
