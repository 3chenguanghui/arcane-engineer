# M3 HUD 三角布局 spec

> 参考范式（只借结构，不复制美术）：动作游戏 HUD 的「角部聚集」——
> 自身状态贴左上、世界状态贴右上、空间地图贴左下、高频操作贴底部中间，中央永远留给战斗。

## 1. 旧版问题
- 生命 / 奥能 / 战绩横铺在整条顶栏，等于在战斗画面上沿切了一条 70px 的"网页导航条"；
- 楼层信息虽然在下左，但地图在右下，信息重心被拆成"左侧两列 + 右侧一列"，读起来要先扫三个角；
- 顶部元素与按钮同宽，第一次玩的人分不清"哪个是状态、哪个是操作"。

## 2. 新版结构
| 角位 | 内容 | 说明 |
| --- | --- | --- |
| 左上 | `.hud-readouts`：生命 / 奥能条 + 战绩 | 竖排卡，"我的状态" |
| 右上 | `.floor-panel`：楼层 / 主题 / 敌人 / 目标 / 房间 / 连杀 / 融合 / 标签 | 竖排卡，"这层世界" |
| 左下 | `.minimap-panel`：楼层地图 | 空间信息，颜色图例保留 |
| 底部 | `.hud-deck`：魔法卡 / 科技模块 / 融合提示 | 高频操作区，未改动 |
| 顶栏 | 品牌 + 按钮组（右对齐） | 只留"机台顶盖"，不再放读数 |

- 面板加宽：楼层面板 158 → 190，主题行允许换行（"机械层 · MECHANICAL" 不再被裁切）。
- 面板材质沿用既有 `body.ui-v2` 装置皮肤（金属底 + 扫描线 + 铆钉），只把 `.hud-readouts` 加进同一组选择器。
- 窄屏（≤1120px）自动回退：读数卡还原为顶栏横排、地图回右下，楼层面板按旧逻辑隐藏。

## 3. 验收（`tools/arcane_m3hud.js`，端口 9511）
| 编号 | 断言 |
| --- | --- |
| M3HUD-1 | 状态卡 left < 30 / top < 130 / 宽 ≤ 240，与右上不重叠 |
| M3HUD-2 | 楼层面板右边缘贴右 ≤ 30 / top < 130，不与地图重叠 |
| M3HUD-3 | 地图 left < 30 且面板中心在下半屏 |
| M3HUD-4 | 四块 HUD 互不遮挡 |
| M3HUD-5 | 屏幕正中 `elementFromPoint` 是画布（无面板覆盖） |
| M3HUD-6 | 卡组完整（魔法卡 ≥1）且生命读数在状态卡内 |
| M3HUD-7 | 帧率 ≥ 90 / 无脚本错误 / 截图 |
