# U2 · 敌人 AI：从「3 套模板」到「威胁语法组合」

> 出处：`.spec/round4-5-merge.md` 结构性根因 **L2**（判定成立）。
> 现状：18 种敌人的 `ai` 字段只有 `chaser / shooter / blink` 三种，其余差异全在 hp / speed / radius。
> 目标：同层同池 5 种怪，打起来能听出/看出 5 种不同节奏，且每种节奏都有前摇与可打断窗口。

---

## 1. 根因（一句话）

**敌人只有「追 / 射 / 闪」三个动词，玩家对任何一种怪的解法都是同一个：后撤 + 瞄准 + 射。**
所以 5 种怪同屏时只是"数值不同的同一场仗"，不是"五种不同的仗"。

## 2. 基本行为块（10 块，全部数据驱动）

| 块 | 一句话 | 前摇 | 可打断 | 关键参数 |
|---|---|---|---|---|
| `chase` | 直线贴近（基础块） | 无 | — | 沿用 conf.speed |
| `kite` | 保持中距离（太近后退 / 太远靠近） | 无 | — | `conf.keepRange` |
| `orbit` | 保持环半径绕圈，切向移动 | 无 | — | `radius 108 / tangent 0.9` |
| `suppress` | 远程压制：短前摇 + 连发 3 发 | 0.32s | 是 | `shots 3 / gap 0.16 / cd 2.8` |
| `charge` | 锁方向蓄力后直线冲锋 | 0.55s | 是 | `dash 0.34 / speed×2.4 / cd 3.4 / 撞墙硬直 0.9` |
| `burst` | 原地蓄力后半径爆发 | 0.78s | 是 | `radius 96 / ×1.6 / cd 4.2` |
| `summon` | 蓄力后召唤同类小体 | 0.90s | 是 | `count 2 / 场上上限 2 / cd 9` |
| `selfdestruct` | 濒死蓄力后自爆（自身死亡） | 0.62s | 是 | `radius 74 / ×1.8 / 触发 hp<35%` |
| `dodge` | 受击后向反方向后撤步 | 0.28s | — | `距离 70 / cd 2.6 / 触发伤害≥12` |
| `shieldRegen` | 4s 未受伤后缓慢回盾 | — | 受伤即停 | `盾 25% hpMax / 回速 6%/s` |

打断统一定义：**前摇期间受到 ≥8 点直接伤害 → 立刻取消当前动作，进入 0.55s 硬直**（`ENEMY_AI_V2_CONFIG.interrupt`）。

## 3. 组合表（每只 2–3 块，同一池覆盖 5 种角色）

### 机械层（第 1 层池）

| 怪 | 块组合 | 角色 | 可观察差异 |
|---|---|---|---|
| `crawler` 履带爬行者 | `chase + charge` | **近战冲锋** | 短前摇 0.55s 后直线扑上来，撞墙会短硬直 |
| `patrol` 巡检机 | `orbit + charge` | **绕圈骚扰** | 先绕着玩家 108px 转圈，冷却好了才蓄力冲锋 |
| `riveter` 铆钉炮台 | `kite + burst` | **蓄力爆发（远程）** | 几乎不动，0.78s 蓄力后 96px 范围爆发 |
| `welder` 焊工构装 | `kite + suppress` | **远程压制** | 中距离停住，三连点射，第三发后有 2.8s 空窗 |
| `assembler` 装配体 | `chase + summon` | **召唤补充** | 追到一半停手 0.9s，召唤 2 只小爬行者（场上 ≤2） |

### 符文层（第 2 层池）

| 怪 | 块组合 | 角色 | 可观察差异 |
|---|---|---|---|
| `runesprite` 符灵 | `orbit + dodge` | **绕圈骚扰** | 贴身绕圈，受击后 70px 后撤步（打不实） |
| `graveter` 碑卫 | `chase + burst` | **蓄力爆发** | 缓慢推进，靠近后 0.78s 震地爆发 |
| `hexer` 咒术体 | `kite + suppress` | **远程压制** | 三连咒弹，节奏固定可数 |
| `cipher` 密文术士 | `kite + summon` | **召唤补充** | 远程站桩，蓄力后召唤 2 只符灵 |
| `warden` 戍卫碑像 | `chase + charge + shieldRegen` | **近战冲锋 + 护盾恢复** | 重冲锋；4s 不被打就回盾，必须持续压制 |

### 虚空层（第 3 层池）

| 怪 | 块组合 | 角色 | 可观察差异 |
|---|---|---|---|
| `stalker` 潜行者 | `blink + orbit + charge` | **绕圈骚扰** | 先绕圈，闪现后接冲锋 |
| `shardling` 裂隙残片 | `chase + selfdestruct` | **近战冲锋（自爆）** | 濒死 0.62s 亮红自爆，必须补刀或远离 |
| `devourer` 虚空吞噬者 | `chase + burst` | **蓄力爆发** | 慢速压迫 + 96px 吞噬脉冲 |
| `screamer` 尖啸者 | `kite + suppress` | **远程压制** | 远处三连尖啸 |
| `riftling` 裂隙幼体 | `blink + summon` | **召唤补充** | 闪现位移 + 0.9s 蓄力召唤碎片 |

> 旧三种（`wanderer / shooter / phaser`）不在区域池，仅保留可用映射（`rush / suppress / orbit`），不影响现有楼层生成。

## 4. 保留约束（一条都不动）

1. 不越房：房间硬边界 `clamp` 逻辑与 `maxLeak` 记录原样保留；冲锋/闪现/后撤步产生的位移仍走 `isWalkableCircle` 与房间 clamp。
2. 进房锁门 / 清房开门：不改 `onRoomCleared` 与开门时序；召唤出的小体带 `isSummoned` 但**计入本房敌人列表**，因此"召唤流"房间必须清掉小体才开门（这是有意的：召唤补充不能变成刷开门捷径）。
3. 走廊巡逻不追人：`enemy.patrol` 分支在 AI 之前 `continue`，行为块完全不参与。
4. 难度三档只在生成时生效：行为块只读 `enemy.damage / speed`（生成时已乘难度），不在运行时改难度。
5. Boss 两阶段不变：`enemy.isBoss` 分支在 AI 之前 `continue`，`updateBossEnemy` 不受影响。

## 5. 验收断言（`tools/arcane_l2.js`，端口 9490）

| # | 断言 | 口径 |
|---|---|---|
| 1 | 角色覆盖 | 3 个池 × 5 角色，`aiV2Coverage()` 返回 `15/15` |
| 2 | 前摇时长 | `riveter` 蓄力 ≥0.7s、`crawler` 冲锋蓄力 ≥0.5s |
| 3 | 可打断 | 前摇中打 10 伤害 → `state` 从 `windup` 变 `recover`，动作不结算 |
| 4 | 不可打断的反例 | 前摇中不打 → 动作照常结算（burst 使玩家掉血） |
| 5 | 保持距离 | `welder` 与玩家距离稳定在 `keepRange ± 60`（不像 chaser 贴脸） |
| 6 | 绕圈 | `runesprite` 连续 3 次采样距离在 `orbit.radius ± 40` 且角度变化 > 0.4rad |
| 7 | 召唤上限 | `assembler` 连续触发 3 次召唤，场上 `isSummoned` 数量 ≤ 2 |
| 8 | 自爆 | `shardling` 打到 30% 血 → 0.62s 后自爆消失，玩家在 74px 内掉血 |
| 9 | 不越房 | 冲锋 + 击退后 `maxLeak ≤ 6px`（沿用旧口径） |
| 10 | A/B | `setAiV2(false)` 后所有怪回到旧 3 套行为，`aiV2().enabled === false` |
| 11 | 同屏节奏 | 一张截图内至少 3 种节奏同时可见（冲锋前摇 / 蓄力圈 / 召唤环） |
| 12 | 性能 | avg fps ≥ 60（跳过前 40 帧预热） |
| 13 | 回归 | 14 套全绿 |

## 6. 设计取舍

- **D1 不在 Boss 上加块**：Boss 已有独立两阶段与地面危险区，本轮只做杂兵威胁语法，避免回归面扩大。
- **D2 召唤体计入房间**：清房判定沿用 `state.enemies.some(e => e.roomId === room.id)`，召唤体天然参与，不改判定逻辑。
- **D3 自爆是濒死行为**（hp<35% 才触发），不是常规攻击，避免小怪变成"必须秒杀"的强约束。
- **D4 打断只认直接伤害**：`damageEnemy()` 入口统一处理，环境/持续伤害同样有效；这与 L1 裂印在入口结算的取舍一致。
- **D5 所有新参数集中在 `ENEMY_AI_V2_CONFIG` + `ENEMY_AI_V2_ROLES`**，调平衡只动这两处；`state.aiV2` 是唯一总开关。
