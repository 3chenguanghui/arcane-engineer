## 1. 五个子系统与验收

### 5.1 影步（冲刺 + 无敌帧）

- 触发：`Space`（主键）/ `Shift`（备用），仅 `mode=playing`。
- 方向：有方向键输入 → 输入方向；否则 → 当前瞄准方向。
- 参数 `DASH_CONFIG`：速度 620 / 持续 0.17s / 无敌 0.32s / 冷却 2.0s。
- 无敌帧：`damagePlayer` 在 `player.invuln > 0` 时直接返回 `applied:0`，不扣血、不闪屏。
- 表现：残影（每 0.02s 采样一张，0.28s 淡出）+ 起步冲击环 + 施法式抖动；冷却中玩家脚下画一圈进度弧。
- 验收：`dash()` 后位移 ≥ 90px；无敌期间 `damagePlayer(10)` 返回 applied=0；冷却中再按无效；0 血场景不触发。

### 5.2 近战前摇

- 之前只有射手/闪现怪有预警，近战贴脸直接掉血（"被偷袭"）。
- 新增 `ENEMY_WINDUP_CONFIG`：`time 0.32s`、`rangePad 18px`、`recover 0.2s`。
- 流程：进入接触范围 → 亮红光 + 收缩圆环 0.32s → 仍在范围内才结算伤害 → 进入原 `contactInterval` 冷却。
- 玩家走出去 → 前摇取消（`windup = 0`）。
- 验收：贴身 0.2s 内 hp 不变；0.45s 后 hp 下降；走开后不掉血。

### 5.3 精英词缀

- 精英生成时随机 1 条（`ELITE_AFFIX_CONFIG`）：
  - `shield 护盾`：额外 35% 血量护盾，青色环；伤害先扣盾，破盾有独立音效/飘字。
  - `swift 迅捷`：移速 ×1.55，带青色拖影。
  - `split 分裂`：死亡时在原地生成 2 只 42% 血量的小残骸（不继承词缀，防链式爆炸）。
  - `vampiric 吸血`：造成接触伤害时回复自身 35% 伤害值。
- 绘制：精英外描边 + 头顶「精英·词缀名」小字（颜色取词缀色）。
- 验收：4 条词缀都能被强制生成并各自生效（护盾吸收、迅捷速度、分裂子体、吸血回血）。

### 5.4 连击终结

- 复用现有连杀计数（`COMBO_CONFIG.step = 5`），每 5 连在原有"奥能 +18"之外追加一次**过载脉冲**：
  - 玩家为中心 150px 内敌人受到 34 伤害（不吃暴击随机，固定值）+ 190 击退；
  - 冲击波环 + 金色顿帧 0.045 + 震屏 5 + 顶部 toast「连击终结 ×N」。
- 防递归：`state.finisherLock` 期间不再触发；同帧多杀只结算一次。
- 验收：摆 6 只低血怪一次清场 → `finisherCount` +1，第二圈敌人被击退且掉血。

### 5.5 动态准星（4 态 + 拖尾 + 落点圈）

- 画布 `cursor: none`，准星改由 Canvas 绘制（面板/标题仍有系统光标）。
- 4 态：
  1. `idle`：青色细环 + 中心点；
  2. `locked`（`aim.targetId` 非空）：金色四角括号 + 内圈；
  3. `cooling`（当前魔法冷却 > 0）：半环进度 + 灰化；
  4. `noAether`（奥能 < 消耗）：红色环 + 缺口。
- 拖尾：最近 8 个屏幕坐标点，按寿命递减半径与透明度。
- 落点圈：当前魔法为「符文雷」时，在预测落点画虚线圆（半径 = 爆炸半径），撞墙时钳制。
- 验收：4 态 class/颜色可断言；拖尾点数随移动增长；落点圈位置在最近可站立点、不穿墙。

## 2. 非目标

- 不做蓄力、不做冲刺攻击、不做地形破坏。
- 不改敌人基础数值曲线（词缀是额外叠加，不改原 hp/伤害公式）。
- 准星不换 SVG 素材（M3 统一素材化）。

## 5. 边界

- 暂停 / 面板打开：影步不触发，准星不画（`mode !== 'playing'`）。
- 冲刺撞墙：该轴停住，另一轴继续，不卡进墙。
- 冲刺中开门/结算：计时归零，回到正常移动。
- 无敌人：前摇与连击终结无目标时只出特效，不报错。
- 词缀精英在走廊：走廊巡逻怪不参与词缀（不生成精英）。
