# U4b · 三个 Boss 各 1 个独有机制

> 出处：`.spec/round4-5-merge.md` 条目 **B6**（"三个 Boss 一套打法"是威胁语法缺失的高潮版）。
> B8（Boss 登场大字）已并入 U8，本单元只做"打法差异"。

---

## 1. 根因（一句话）

**三只 Boss 的差异主要在外观和数值，真正改变玩家走位的只有三招重招（震波 / 符文雨 / 奇点），而重招是轮转的第 3 招——大多数时间玩家面对的是同一套"环形弹幕 + 扇形弹幕"。**

拆开看：
- 机械：贴脸 + 重招震波，玩家永远在"贴近打 / 退开躲"；
- 符文：控距 + 闪现 + 符文雨，打法其实和"躲地面圈"没有区别；
- 虚空：游走 + 奇点吸引，重招和符文雨共享同一个"地面危险区"手感。

**三只 Boss 缺的是"一个只有它会做、并且必须改变你的动作"的招牌机制。**

## 2. 改法：一 Boss 一招牌（都基于已有原语：telegraph / hazards / 弹幕）

| Boss | 招牌 | 行为 | 可观察差异 |
|---|---|---|---|
| 机械暴君 | **核心过载** | 每 9s 蓄力 1.0s → 环形弹幕 → 进入 **2.4s 核心暴露**：受伤 ×1.5、移速 ×0.6 | 屏幕上多一个"该冲上去打"的窗口（和"该退"形成节奏） |
| 符文织者 | **连环刻印** | 每 8s 沿"首领→玩家"射线铺 3 个刻印，间隔 0.5s **依次**引爆 | 地面危险区不再同时出现，而是"一路追着你爆" |
| 虚空噬主 | **引力井** | 每 10s 在"首领↔玩家"连线中点开 1.6s 引力井（半径 150、吸力 150px/s），结束时内爆 22 | 玩家会被"往中心拖"，必须提前走位或冲刺脱身 |

数值（`BOSS_SIG_CONFIG`）：

```js
mech: { id:'overload',    windup:1.0, cooldown:9.0, coreOpen:2.4, coreDamageMul:1.5, coreSpeedMul:0.6 }
rune: { id:'runeChain',   cooldown:8.0, count:3, gap:0.5, damageMul:1.0 }
void: { id:'gravityWell', windup:1.6, cooldown:10.0, radius:150, damage:22, pull:150 }
```

二阶段：冷却 ×0.75（更频繁），但**前摇不下调**（保留反应窗口）。

## 3. 保留约束

- Boss 两阶段机制不变：50% 血进入二阶段、转换演出无敌、重招轮转与数值不动。
- 重招（slam / runeRain / singularity）保持原样，招牌机制是**独立计时器**，不抢 `attackIndex`。
- 招牌只在 `started`（玩家已进房、登场演出结束）后才开始计时，不会隔墙偷袭。
- 不越房、不清房、不改掉落与结算。
- 全部数据驱动 + `state.bossSigV1` A/B 开关（`false` 时行为完全回到本单元之前）。

| # | 断言 | 口径 |
|---|---|---|

## 5. 设计取舍

- **D1 机械的招牌是"挨打的窗口"而不是新招式**：三只 Boss 里机械最"莽"，给它"打爆核心"的奖励窗口，逼玩家从"躲"切到"冲"，节奏差最大。
- **D2 符文用"依次引爆"而不是"更大范围"**：范围只会让玩家退更多，依次引爆才会让玩家"横着走"，动作不一样。
- **D3 虚空用牵引而不是新弹幕**：已有 singularity 的牵引是最有辨识度的力场手感，把它独立成招牌（更频繁 + 更小半径 + 固定 22 伤害），不新增系统。井心放在**连线中点**（不是玩家脚下）：开在脚下等于玩家本来就在中心，牵引没有手感。
- **D4 前摇不随二阶段缩短**：Boss 已经够压迫，前摇缩短会把"可打断 / 可躲"的公平感吃掉。
