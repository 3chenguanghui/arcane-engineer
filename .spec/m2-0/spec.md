# M2-0 分支地图 · 大世界 · 战争迷雾 · 对象池/裁剪

## 1. 目标（用户可感知）
1. **地图真的分岔**：不再是"一条从左到右的链"，玩家清完一间房后能看到 1–2 个方向可选，形成"走哪条线"的决策。
2. **世界更大**：1800×1300 → **2600×1900**，房间之间留出更长的走廊，探索感更强（为 M2 房间放大与 Boss 房留空间）。
3. **战争迷雾**：没进过的房间在画面与小地图上都是黑的；进入后永久点亮（本层内），小地图只显示已探索区域。
4. **性能不倒退**：整张底图不再每帧全贴，只贴镜头附近；粒子不再无限 new 对象（对象池复用）。帧率 ≥ 60、errors 为空。

## 2. 方案
### 2.1 世界尺寸
`GAME_CONFIG.worldWidth = 2600`、`worldHeight = 1900`。

### 2.2 三列分带 + 前向分支
- 新增 `GAME_CONFIG.roomColumns = 3`。
- `buildBranchingRooms(count)`：把可用宽度按 3 列均分，房间数 4–7 平均分到每列（余数随机分配，每列至少 1 间）；
  列内按"行带"依次摆放，保证同列不重叠；每间房在自己的列带内留 ≥50px 边距，避免跨列贴脸。
- `connectBranchingRooms()`：
  - **保连通**：第 i 列每间房 → 连到第 i-1 列里"纵向最近"的一间（等价最小生成，保证从出生点可达）。
  - **造分支**：第 i-1 列中没有出边的房间，再补一条到本列另一间（形成"一房两门"）。
- 出生房 = 第 0 列的房间；楼梯房 = 距出生房最远的房间（仍在最后一列）。

### 2.3 战争迷雾
- 状态：`state.fog = { seenRooms: {}, seenCorridors: {} }`；换层重置，出生房与其相连走廊默认已见。
- 揭示：`updateRoomLogic` 里 `currentRoomId` 变化 → `revealRoom(room)`（房间 + 与该房相连的走廊矩形）。
- 渲染：视口大小的离屏 `fogCanvas`，铺 `rgba(4,7,13,0.94)` 深色，再用 `destination-out` 在已见矩形上"擦洞"（三层内缩做羽化边）；最后贴到屏幕层（在像素后处理与准星之前）。
- 小地图：未探索房间/走廊不画；敌人与楼梯只画在已探索区域。

### 2.4 对象池 + 视口裁剪
- `drawScene()` 用**源矩形裁剪**：只贴 `cam ± 24px` 的世界区域（含震屏余量）。
- 粒子对象池：`acquireParticle() / releaseParticle()`，死亡粒子回池（上限 400），4 个生成点全部走池。
- 粒子绘制前做视口裁剪，统计 `drawn / culled` 写进 `state.drawStats`，供自动化断言。

## 3. 验收（tools/arcane_m18.js）
1. 世界尺寸 2600×1900。
2. 每层房间 4–7 且分列 ≥ 2；`layout.edges` 数 ≥ 房间数 - 1；存在 ≥1 间房有 2 条前向边（真分支）。
3. 从出生房出发，按 edges 做 BFS 能到达全部房间与楼梯房。
4. 迷雾：开局只点亮出生房（≤2 间）；teleport 进未探索房后该房点亮、相连走廊点亮；小地图同步（fog.seenRooms 增加）。
5. 裁剪：`drawStats.culledParticles > 0` 或镜头移动后 `sceneSrc` 尺寸 < 世界尺寸；粒子池复用（连发多次 burst 后池长度 > 0 且总对象数不线性增长）。
6. 帧率 ≥ 60、errors 为空、无报错。
