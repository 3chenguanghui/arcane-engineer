# 第 25 项 · 近战武器系统规格（自裁决版）

> 状态：定稿，直接执行，不再请求批准。
> 依赖：第 13 项大区 / 第 14 项挑战等级均已上线；本项不修改任何已 PASS 断言的阈值。

## 1. 目标与非目标

- 目标：在现有"魔法卡 + 科技模块"之外，增加一条**不耗奥能**的近战副输出线：
  5 把形态不同的武器、4 条改造、完整手感（挥击弧线 / 顿帧 / 击退 / 震屏 / 音效 / 输入缓冲 / 连段），
  并给出**三种口径**的 DPS 对照，证明武器之间不是换皮。
- 非目标：不改魔法伤害、不改奖励池结构、不改元素附着表、不改难度曲线。
  武器默认 `noElement`，避免与第 1 项元素系统、第 14 项挑战数值互相污染。

## 2. 自裁决项（6 处，及为什么不选另一种）

| # | 决策 | 为什么不选另一种 |
|---|---|---|
| D1 | 武器在**标题页选择**并写入 `meta.weaponId`，开局继承；局内可用调试口切换 | 不在奖励池插入第 5 类选项：奖励池已被 13/14 与多项断言依赖，插入会放大回归面 |
| D2 | 4 条改造按楼层**自动装配**：F3 锋锐、F6 疾风、F9 延展、F12 破甲 | 不做四选一弹窗：奖励 UI 与"三选一/四选一"断言耦合，改它风险高于收益；自动装配保证每局都能体验完整改造 |
| D3 | 攻击键为 **Q**（键盘），不做鼠标绑定 | 左键=主技能、右键=装置，已被大量断言与玩家习惯占用；Q 与 WASD 相邻，副手手感自然 |
| D4 | 武器伤害走既有 `damageEnemy`，`abilityId='weapon:<id>'` 且 `noElement:true` | 不新增元素源：元素表是第 1 项已 PASS 的封闭集合，新增会改变反应统计 |

## 3. 五把武器（形态必须不同，不是换数字）

| id | 名称 | 形态 | 关键参数（首版） | 定位 |
|---|---|---|---|---|
| `dagger` | 导轨短刃 | 短弧 ×3 连段，第三段 ×1.35 | 伤 14 / 冷 0.36s / 半径 72 / 弧 90° / 连段 3 | 最快、最短、DPS 稳定 |
| `longsword` | 熔核长刀 | 宽弧单段，命中全弧 | 伤 30 / 冷 0.72s / 半径 96 / 弧 120° | 中庸全能 |
| `hammer` | 共振战锤 | 窄弧重击 + 落点冲击环，强击退 | 伤 58 / 冷 1.15s / 半径 86 / 弧 75° / 击退 ×2.2 | 单发最重、最慢 |
| `twin` | 镜像双刃 | 前后两个 80° 弧，各 2 段 | 伤 9×2 / 冷 0.34s / 半径 68 / 各弧 80° | 被围时群伤最高 |
| `spear` | 相位长枪 | 直线贯穿，命中路径上全部敌人 | 伤 24 / 冷 0.62s / 半径 140 / 线宽 26 | 最远、单体中上、可贯线 |

所有武器共享：`cooldown` 受改造与天赋无关（不接 CDR，避免与第 11 项叠乘失控），

## 5. 手感配套

- 输入缓冲：冷却中按 Q 会缓存**一次**挥击意图，不随时间衰减，冷却结束立刻补发；
  只缓存一次（连按不会排队成多刀），避免"重武器冷却里按了却无声吞掉"。
- 连段窗口 0.75s：短刃三段连击，超时回到第一段；每段左右交替挥击。
- 挥击弧线：世界层绘制 0.22s 渐隐弧带 + 刀尖拖尾；双刃画前后两道；长枪画直线残影。
- 命中反馈全部复用既有 `damageEnemy`：顿帧 / 飘字 / 击退 / 火花 / 音效。
- 武器自身额外：战锤落点冲击环 + 3.5 震屏；短刃每段 `playSfx('ui')`；长枪贯穿每命中 +1 音高。
- 空挥（未命中）不触发顿帧与震屏，只出一声轻响，避免"打空气也卡"。
- 冲刺 / 转场 / 结算 / 暂停期间禁止挥击；`state.weapon.swing` 只做表现，不参与碰撞。
- 大区、深度模式、三档难度、挑战等级 0–10 全部可用（武器不读难度倍率）。

## 6. 三种 DPS 口径（验收脚本输出同一张表）

1. **理论单体** `single`：`damage × hits × comboAvg / cooldown(改造后)`，不计暴击、不计空挥。
2. **群怪有效** `group`：标准 7 假人布局上用真实几何命中并乘以命中数 ——
   正前 40 / 80 / 120px 三只（考射程与贯穿）、左右 70px ±45° 两只（考弧宽）、
   身后 55px ±150° 两只（考双刃后向覆盖）；用来区分"宽弧 / 双刃 / 长枪"。
3. **实战** `real`：真实冷却 + 输入缓冲 + 暴击期望（`FEEL_CONFIG.critChance × critMul`）
   + 40% 走位空窗（`uptime=0.60`）；作为"玩家实际能打出的下限"。

验收带：`single` 落在 30–60；`group` 至少比 `single` 高 15%（双刃/长枪 ≥30%）；`real` 落在 18–50；
三把以上武器的 `single` 两两差值 ≥8%（不是换皮）。

## 7. 总开关与降级

- `WEAPON_CONFIG.enabled=false` 或 `meta.weaponsEnabled=false`：Q 无响应、标题武器行隐藏、
  HUD 武器条隐藏、`updateWeapon` 直接返回、绘制不产生任何额外调用。
- 关闭后再开启必须恢复同一把武器与已装配改造（都来自 `state.weapon` / `meta.weaponId`）。
- 不产生外部请求；不新增素材；全部 Canvas 程序化。

## 8. 存档

- 局内快照新增 `state.weapon = { id, mods{4}, combo, comboTimer, cd, swing, stats }`；
  旧档缺该字段时由 `ensureWeaponState` 按 `meta.weaponId` 补默认，不崩、不丢楼层。
- 永久档案新增 `meta.weaponId`（合法 id 才保留，否则回 `dagger`）与 `meta.weaponsEnabled`（默认 true）。
- `META_SCHEMA_VERSION` 保持 9：两项都是**可选补字段**，`normalizeMeta` 缺省补齐即可，
  不升版本可避免所有既有迁移断言（v9 口径）无谓失效。
