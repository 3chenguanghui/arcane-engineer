# M2 故事线（spec）

> 优先级：B3 收口后第一块。目标不是"加文字量"，而是让塔灵从"死亡面板里的一段话"变成**整局一直在的声音**，
> 并补上环境叙事与结局收束。

## 1. 现状与缺口
- 已有：`U5_CONFIG`（9 类死因 × 2 句 + 3 条首领专属台词）、死亡演出、结算自传。
- 缺口：
  1. 塔灵只在死亡时出现，玩家 5 层全程听不到"叙事声音"；
  2. 死因旁白是通用句，和"这一局怎么打的"无关；
  3. 没有环境叙事——三层只有配色差异，墙是墙、地板是地板；
  4. 通关面板只有数据 + 自传，没有"结局感"（后日谈）。

## 2. 方案（四块，全部纯字符串 + 一个 HUD 行）
### 2.1 塔灵常驻旁白 `SPIRIT_CONFIG`
- 载体：新增 `#spiritLine`（顶部提示条下方一行，青色竖线 + ✦）。
  **不复用 `toast`**：toast 是系统反馈（奥能不足 / 清层奖励），叙事与系统反馈抢同一行会互相覆盖。
- 队列机制：`spiritQueue` 去重（同一句一局只说一次）→ `maxQueue 3` 截断 → `spiritTick(dt)` 按
  `dwell 4.2s / minGap 0.75s` 播报。`spiritTick` 吃真实时间，不受顿帧与慢动作影响。
- 事件与挂点：
  | 事件 | 挂点 |
  | --- | --- |
  | `runStart` | `startGame()` |
  | `descend`（按楼层取句） | `descendFloor()` |
  | `boss`（按主题取句） | `spawnBoss()` |
  | `lowHp`（每局一次） | `damagePlayer()` 低血阈值块 |
  | `fusion` | `tryFuse()` 成功后 |
  | `epic` | `applyReward()` 拿到史诗奖励时 |
  | `pactCurse` | `applyReward()` 贪婪回路分支 |
  | `clear` | `checkFloorClear()` |
- 选句：`(floor + kills + storyShown) % lines.length`，同局稳定，自动化可断言。

### 2.2 环境叙事 `SPIRIT_CONFIG.lore`
- 每个主题 2 段「墙上的铭文」（机械 / 符文 / 虚空），进层时按 `loreIndex` 轮换，带小标签（`铭文 · 装配序列`）。
- 不新增场景物件、不改地图生成——零渲染开销，只借用旁白行。
- 文案锚定既有世界观：装配序列、复写符文、地板厚度上限（与三层主题、Boss 机制同源）。

### 2.3 死因旁白第二句 `deathContextLine()`
- 在 U5 通用台词之下再补一句"针对本局"的话，优先级：
  1. 第 1 层就死 → "还没来得及写你这一段"；
  2. 全程 0 融合 → "原始线路也能走到这里"；
  3. 签过诅咒契约 → "它现在结清了"；
  4. 到达 ≥ 第 4 层 → "这段记录比大多数都长"；
  5. 其他 → "第 n 层的门，下一次会记得你"。
- 渲染为 `.tower-context`（虚线分隔，比主台词更淡），只在死亡面板出现。

### 2.4 结局后日谈 `buildEpilogueLines()` / `buildEpilogueHtml()`
- 通关面板在自传之后追加 `.run-epilogue`：
  - 首次通关 / 重复通关 / 老玩家（runs ≥ 8）三选一；
  - 有融合 vs 全程无融合；
  - 签过契约（祝福或诅咒）追加一句；
  - 固定收尾句 `towerLast`（"我记得每一台机体的开场，也记得你怎么结束"）。

## 3. 开关与兼容
- `SPIRIT_CONFIG.enabled`（模块级）与 `state.m2V1`（局级 A/B）：任一为 false → 旁白、铭文、死因第二句、后日谈全部不出现。
- 纯表现层：不改 AI / 伤害 / 奖励池 / 清房 / 存档结构（只新增 `state.spirit` 与 `state.m2V1`，不写 saveMeta）。
- 性能：每帧只做「减两个计时器 + 必要时取一句」，DOM 只在换句时写一次。
