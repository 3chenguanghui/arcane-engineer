# 单元 C · 角色与怪物美术（spec）

> 目标：把玩家与怪物从「几何色块」提升到「40px 下可辨识的剪影 + 有生命感的动作 + 统一的受光/受击语言」。
> 硬约束：单文件零依赖、纯程序化绘制（无图片/无音频文件）、四向朝向系统与现有玩法判定不变。

## 一、玩家（3 段剪影 + 5 种动作）

| 项 | 现状 | 目标 |
|---|---|---|
| 剪影结构 | 身体 + 小三角 | **披风 / 法杖 / 头冠** 三段可辨；40px 缩放后仍能读出「法师」轮廓 |
| 待机 | 上下浮动 + 呼吸缩放 | 保留浮动，呼吸改为「胸腔起伏 + 头冠微摆」，周期 2.2s |
| 行走 | 无帧动画 | 4–8 帧循环（脚部 2 组交替 + 披风摆动相位），移动时启用、静止时淡出 |
| 施法 | `castAnim` 抬手 | 前摇 0.18s（杖头汇聚光点）+ 后摇 0.12s（杖身回弹），与 `castAnim` 同源 |
| 受伤 | 无 | 挤压 0.9→1.08 倍 + 闪白 2 帧 + 边缘红晕，0.25s 回弹 |
| 披风二级运动 | 无 | 简化摆锤：`clothAngle += (target - angle) * k`，跟随移动方向滞后 6–10 帧 |

统一：落地投影（已有）、**边缘光**（背光侧 1px 亮边，随房间主光方向）、**轮廓描边**（深色 1px）、命中闪白。

## 二、怪物（三层 × 5 种，形状/配色/动作三重区分）

| 层 | 命名方向 | 形状语言 | 动作语言 |
|---|---|---|---|
| 机械 | 齿轮体 / 活塞臂 / 管线虫 / 焊枪头 / 铆钉墩 | 方形、硬边、金属反光 | 齿转、活塞往复、硬顿挫 |
| 符文 | 石像 / 浮文法阵 / 藤蔓典籍 / 双翼符灵 / 碑灵 | 圆/菱形、对称、发光刻纹 | 漂浮、脉动、符文旋转 |
| 虚空 | 裂隙触手 / 眼球体 / 碎屑群 / 低语影 / 虚空核 | 破缺轮廓、拖尾、负空间 | 抖动、压缩-拉伸、瞬移残影 |

每种四态：待机 / 移动 / 攻击前摇 / 受击 / 死亡；前摇必须有「可读的蓄力形变」（0.25–0.35s）。
精英词缀可视化：护盾环（shield）/ 加速尾焰（haste）/ 分裂残影（split）/ 吸血脉冲（leech）。
Boss 分部件：躯干 / 臂 / 核心 / 尖刺 各自独立相位（核心呼吸、臂摆动、尖刺伸缩）。

## 三、统一受光与受击语言

- 接触阴影：所有单位统一椭圆投影（尺寸按半径，透明度 0.35–0.5）。
- 边缘光方向：跟随房间主光（A1 已记录 `mainLight` 方向），背光侧描亮边。
- 命中闪白：与 `FEEL_CONFIG` 顿帧同步，2 帧峰值 + 0.12s 衰减。
- 死亡碎裂：复用 `PIXEL_FX_CONFIG.shatter` + `FEEL_CONFIG.killBurst`，不新增系统。

## 四、验收

1. 每类单位 2x 特写截图（玩家 + 三层代表怪 + 精英 + Boss）→ `.screenshots/art/c-*.png`
2. 40px 剪影识别：把每个单位缩到 40px 高，比较「非透明像素包围盒宽高比 + 边缘复杂度」，要求同层 5 种两两可区分（差异 ≥ 阈值）
3. 动画帧数断言：行走循环帧数 4–8；受击/前摇时长在区间；披风滞后 6–10 帧
4. 统一性断言：全场单位投影数量 = 单位数量；边缘光方向与主光一致；命中闪白存在
5. fps ≥ 60（1440×900 dsf 1），帧耗时 ≤ 16.7ms
6. 核心 14 套回归全绿

## 五、不做（本轮）

- 不引入骨骼/关键帧文件；所有帧由代码参数化生成。
- 不改碰撞半径、攻击判定、伤害数值（外观与判定解耦）。
- 暂不做受击方向的分层动画（只做整体挤压 + 闪白）。
