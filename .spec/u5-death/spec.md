# U5 · 塔灵死因台词 + 结算自传

> 出处：`.spec/round4-5-merge.md` 条目 **C9（塔灵 + 死因分支台词）** 与 **C10（结算页 = 一局的自传）**，同时并入 **B5 / B4 的表现包尾项**。
> 现状：`damagePlayer()` 只收 `(amount, sourceX, sourceY)`，死亡后 `showResult()` 只报 6 个数字；
> 玩家死时不知道"被什么打死"，死后也读不到"这局我到底打了什么"。

---

## 1. 根因（一句话）

**伤害没有来源身份，结算没有叙事**——死亡是一个数字（hp 归零），不是一个事件；
结算页是一张成绩单，不是一段可以复述的经历。

## 2. 改法 A：死因链路（伤害带身份）

1. `damagePlayer(amount, sx, sy, cause)` 新增第 4 个可选参数：
   `cause = { kind, name }`，`kind` 是枚举，`name` 是可读来源（怪名 / 首领名 / "弹幕"）。
2. 每次**真实扣血**时写 `state.lastHit = { kind, name, amount, at }`（被无敌帧完全挡掉不算）。
3. 全量调用点补 `cause`：

| 调用点 | kind | name |
|---|---|---|
| 敌人贴身接触 | `contact` | 怪名（`enemy.name`） |
| 冲锋撞击 | `charge` | 怪名 |
| 蓄力爆发波及 | `burst` | 怪名 |
| 濒死自爆 | `selfdestruct` | 怪名 |
| 敌方 / 首领弹幕 | `bullet` | 怪名或 `首领弹幕` |
| 地面危险区（落锤 / 环 / 引力井） | `hazard` | 首领名 |
| 未知 / 调试 | `unknown` | `未知来源` |

4. `resolveDeathCause()`：把 `state.lastHit` 映射成 `{ kind, label, quote, extra }`；
   **首领优先级最高**：任何来自首领的伤害都走"首领专属台词"，避免"被最终 Boss 打死却说被小兵撞死"。

## 3. 改法 B：塔灵台词（7 类 × 2 句）

塔灵人设：一个守着这座塔、语气冷静到有点刻薄的记录者。台词只陈述"你是怎么走的"，不劝氪、不煽情。

| kind | 台词 A | 台词 B |
|---|---|---|
| `contact` | 你让构装贴到了身上，还站在原地数它的铆钉。 | 贴身的铁块从不讲道理，它只需要你不动。 |
| `charge` | 你看见了那条锁定线，然后决定从线上走过去。 | 冲锋的预警是给你的，不是给它的。 |
| `burst` | 你站在了爆发圈的圆心，像在等一场雨。 | 蓄力的三秒里，你选择了最亮的那一格地砖。 |
| `bullet` | 弹幕是一条线，你却站在原地等它画完。 | 你数对了三连发，只是没数对自己的血。 |
| `hazard` | 地面的警示圈不是装饰，我画它是有原因的。 | 你踩进了我留给你的那块地，正中圆心。 |
| `selfdestruct` | 它亮起来的时候，你凑近了看。 | 那声倒计时不是背景音。 |
| `unknown` | 信号断了，我甚至没看清是什么碰了你。 | 这一下不在我的记录里，但血确实少了。 |

首领台词（按 `bossKind`，优先级高于 kind）：
- `mech`：`机器不会可怜你，它只是按节拍把核心转向你。`
- `rune`：`刻印落在你脚边三次，你三次都站在原地。`
- `void`：`引力井不是在拉你，是在替你选一个落点。`

## 4. 改法 C：结算自传（3 句，死亡 / 通关共用）

`buildRunAutobiography()` 输出一段话：

1. **路线句**：`你从第 1 层走到第 {floor} 层，用了 {时长}，清空 {floorsCleared} 层。`
2. **战力句**：`击杀 {kills} 只构装；最锋利的一击是 {amount} 点，落在 {target} 身上。`
3. **构筑句**：`带着 {magic}+{tech}+{fusion} 件构筑，标签覆盖 {n}/9；从没碰过 {缺失标签}。`

- "最锋利一击"由 `damageEnemy()` 统一记录（`state.runBest`），只记最终结算后伤害（含暴击/裂印/核心暴露）。
- "从没碰过的标签"由 `tagLevels()` 反推（层数为 0 的标签），最多列 3 个。
- 死亡面板与通关面板都插入同一段自传，位置在数字统计之前，保证"先读故事再看数字"。

## 5. 保留约束（一条都不动）

1. **不延迟结算面板**：`loseGame()` 依然立刻 `showResult()`；塔灵台词写在面板里，不改状态机，避免影响 m20 / m25 对 `status=dead → modalVisible` 的即时断言。
2. **不改伤害数值**：`cause` 只记录，不参与任何倍率。
3. **不改通关流程**：`winGame / continueEndless` 原样；只往 `showVictory()` 里插同一段自传。
4. **不改存档结构**：自传是运行时字符串，不写 `localStorage`。
5. 单文件零依赖，台词全部中文字符串，零美术。

## 6. 验收断言（`tools/arcane_u5.js`，端口 9496）

| # | 断言 | 口径 |
|---|---|---|
| 1 | 开关与台词表 | `u5Audit()`：`enabled=true`、7 类 kind、每类 2 句、3 条首领台词 |
| 2 | 接触死因 | 被构装撞死 → `data-death-cause="contact"`，台词命中该类 |
| 3 | 冲锋死因 | `cause=charge`，台词与 contact 不同 |
| 4 | 弹幕死因 | `cause=bullet` |
| 5 | 自爆死因 | `cause=selfdestruct` |
| 6 | 危险区死因 | `cause=hazard` |
| 7 | 首领优先 | 被首领打死 → 台词含首领名 / 首领专属句，不落回 kind |
| 8 | 至少 5 类专属 | `covered >= 5`（7 类中） |
| 9 | 自传三要素 | 文本含"用了"、"最锋利的一击"、"从没碰过" |
| 10 | 最锋利一击 | `damageEnemy` 打 200 → `runBest.amount >= 200` 且自传数字同步 |

| 14 | 性能 | avg fps ≥ 60、errors 0、截图 > 10KB |

## 7. 设计取舍

- **D1 台词不随机**：用 `(floor + kills) % 2` 选 A/B 句，保证自动化断言稳定；玩家仍能听到两种语气。
- **D2 首领优先级**：`lastHit.bossKind` 存在时覆盖 kind，因为"被最终 Boss 的环弹打死"比"被弹幕打死"更有叙事价值。
- **D3 自传只在结算出现**：不做战斗内实时叙事，避免 HUD 继续变重。
- **D4 死亡演出不新增状态机**：沿用现有红闪 / 震屏 / 爆点 / glitch / 死亡音 + BGM 淡出，U5 只加"塔灵台词框"，把风险压在字符串层。
- **D5 最锋利一击含所有来源**：环境、无人机、融合都算，因为它问的是"这局最亮的一下"，不是"玩家手打的一下"。
