# U9 · 标题屏减法 + 动态背景 + 游戏内情境提示

> 出处：`.spec/round4-5-merge.md` **D1**（标题屏动态背景）、**D2**（7 条引导移出标题屏）、**D3**（统一母题：六边星 + 电路节点）、**D5**（只做"靠近提示"，不改首敌 AI）。
> 验收目标：**标题首屏引导从 7 条降到 0 条，背景在动**。

---

## 1. 根因

1. **标题屏是说明书，不是招牌**：7 条 `guide-item` 把首屏撑成"键位表"，玩家第一眼读的是操作说明，不是"这是一款什么游戏"；主题介绍（机械/符文/虚空）同样是第二局才知道有用的信息。
2. **背景是死的**：`.title-layer::before` 只有一层静态径向渐变，没有"塔在运转"的感觉；首屏与游戏内是两种质感。
3. **母题只存在于 HUD 与地面**：卡片四角有支架、地面有符文圈，但没有一个贯穿"标题 / HUD / 结算"的识别符号。
4. **引导时机错了**：玩家在标题屏读完 7 条，进游戏时已经忘了 5 条；真正需要提示的时刻是"第一次要下楼 / 第一次靠近宝箱"。

## 2. 改法

### A. 标题屏减法（D2）
- 删除 `.title-themes`（3 条主题介绍）与 `.title-guide`（7 条键位说明）。
- 保留：`kicker`、`h1`、`tagline`、3 项 `title-stats`、难度选择、永久天赋、`开始探索`、底部一行极简脚注（"对局中按 H 看帮助"）。
- `.title-duo` 保留两列（左难度 / 右天赋），删掉引导后标题卡片高度下降约 1/3。

### B. 动态背景（D1）
- 新增 `<canvas id="titleBg" class="title-bg">`，绝对定位铺满、`z-index` 在卡片之下。
- `drawTitleBackground(t)` 每帧画 4 层（全部程序化、零图片）：
  1. **底**：深蓝黑径向渐变 + 缓慢漂移的星点；
  2. **符文环**：两层六边形环（外环顺时针、内环逆时针），节点处画电路短线；
  3. **微粒**：48 颗上升尘粒（确定性 seed，循环回收）；
  4. **主角剪影**：右下角一个低亮度剪影（披风梯形 + 头 + 法杖 + 法杖端光点），复用游戏内 `drawPlayer` 的比例，但不带任何 HUD。
- 只在 `titleLayer` 可见时 `requestAnimationFrame`；进入游戏即停（不占战斗帧）。

### C. 母题统一（D3）
- 新增 `.title-sigil`：CSS `clip-path` 六边形 + 内部两个电路节点（伪元素），放在 `kicker` 左侧；与背景外环、HUD 角标同一形状语言。

### D. 游戏内情境提示（D2 + D5）
- 新增 `state.contextHint = { text, sub, until, key }` 与 HUD 底部 `.context-hint`。
- 三类提示（只提示，不改任何 AI / 碰撞）：
  1. **首局三步**（`meta.runs === 0` 且 `meta.hintsSeen` 未置位）：0–5s「WASD 移动」→ 5–10s「左键施法」→ 10–15s「空格影步」；结束后写 `meta.hintsSeen = 1`（一次性）。
  2. **靠近楼梯**：距楼梯中心 < 90px 且本层已清 → 「按 E 下楼」。
  3. **靠近宝箱**：距宝箱 < 70px → 「按 E 开启宝箱」。
- 提示条 5s 内淡入、离开即消失；同一 key 不重复弹。

### E. A/B 开关
`state.u9V1`：`false` 时标题屏回到旧版（恢复 `title-themes` + `title-guide` 的 DOM，停背景动画），用于对照截图。

## 3. 保留约束

1. 不复用 `floorWipe` 做转场（D4 已判定不做）。
2. 不改首敌 AI、不改落闸/清房流程（m20 / m25 依赖）。
3. 不新增外部资源；背景全部 Canvas 程序化。
4. 字号下限 11px；标题卡片在 1280×720 下不横向溢出（m12/m14 覆盖）。
5. `Enter` 开始、难度选择、天赋购买的行为不变。

## 5. 取舍

- **D1 不做 CSS 动画背景**：canvas 才能同时画环 + 微粒 + 剪影且不增加 DOM；停绘逻辑简单（`titleLayer` 隐藏即 cancel）。
- **D2 不删难度/天赋**：它们是决策项不是说明项，删了会让"开始"变成盲选。
- **D3 只统一"角标 + 符文环"**：全量重绘 HUD 成本高、回归面大。
- **D5 不改首敌 AI**：m20 的落闸 / 清房断言依赖敌人主动行为。
- **提示一次性写进 `meta`**：跨局保留，避免第二局再被"WASD"打断。
